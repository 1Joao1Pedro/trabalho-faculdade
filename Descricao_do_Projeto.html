DESCRIÇÃO DO PROJETO

Cadastro Seguro

Sistema de cadastro e gerenciamento de usuários

Nosso projeto é um sistema web para cadastrar e gerenciar usuários. A ideia é ter uma tela simples de cadastro e uma área administrativa para consultar e organizar as contas criadas, com acesso controlado de acordo com o perfil de cada pessoa.

Como funciona

Na tela de cadastro, a pessoa informa nome, e-mail e senha. Depois de entrar no sistema, ela pode consultar e atualizar seus próprios dados. Todo cadastro feito pela tela pública recebe o perfil de usuário comum.

O administrador tem acesso a um painel com a lista de usuários cadastrados. Nesse painel, ele pode pesquisar por nome ou e-mail, editar informações e excluir contas de usuários comuns. Também pode consultar o histórico das ações realizadas no sistema.

Segurança e armazenamento

O sistema exige login para acessar as áreas protegidas e verifica as permissões antes de executar cada operação. Assim, um usuário comum não consegue abrir a área administrativa, mesmo tentando acessar o endereço diretamente.

As senhas são armazenadas como hash, e não em texto puro. Os formulários validam os dados recebidos, como campos obrigatórios e e-mails já cadastrados. Também há um limite de tentativas de login e um histórico que registra eventos como entradas, falhas de login, alterações, exclusões e tentativas de acesso sem permissão.

Os dados ficam em um banco MySQL executado no Docker, com armazenamento persistente. A aplicação foi desenvolvida em PHP com Laravel, usando Blade, HTML, CSS e JavaScript nas telas.

Desenvolvimento e objetivo

O desenvolvimento foi organizado em etapas: definição dos requisitos, cadastro e login, painel administrativo, histórico de ações e testes. Foram realizados testes automatizados para verificar o funcionamento das telas e situações como senha incorreta, dados inválidos e acesso sem autorização.

O objetivo é mostrar, de forma prática, como um sistema de cadastro pode organizar informações e proteger o acesso aos dados com autenticação, permissões e registro de ações.
